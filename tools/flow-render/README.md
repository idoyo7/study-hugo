# 도식 렌더 스모크

브라우저 없이 단계형 도식 엔진을 최소 DOM 스텁 위에서 돌려 깨진 좌표를 잡는다.

```
node tools/flow-render/rstep-smoke.js static/flow/rstep.js
```

`variant × phase × t` 격자(3 × 5 × 12, 두 바퀴 + `ts === 0` 한 점)를 훑어
`NaN`·`undefined` 속성, viewBox 이탈, 음수 `width`/`r`, 범위 밖 `opacity`, 빈 caption 을 본다.

**한 시점만 보면 안 된다.** 단계형 엔진은 특정 단계에서만 음수 폭이 나오는 식으로 깨진다.
`ts === 0` 을 따로 넣는 이유는 `if (!t0) t0 = ts` 함정 회귀 검사다 —
첫 타임스탬프가 정확히 0 이면 시작 시각이 영영 안 잡힌다. 엔진은 `t0 = -1` / `if (t0 < 0)` 로 둔다.

숨겨진(`opacity="0"`) 요소는 이탈 검사에서 빼지만 좌표 자체는 유효해야 한다 — 대기 위치를 viewBox
밖에 두면 확대 보기에서 드러난다.

검사기가 실제로 작동하는지 확인하려면 상수를 일부러 깨서 FAIL 이 나는지 본다.
