- 내비게이션 검사 통과: HTML 399개, 경로·리소스 1,959개를 기준 빌드와 비교. 기존 URL, 로컬 링크·앵커, canonical, 사이드바 상태 검사 포함.
- `python3 -m unittest discover -s tools/tests -p 'test_*.py'`: 테스트 17개 통과.

게시글의 외부 출처·가격·버전 정보는 이번에 새로 조사하지 않았다. 실행 증거와 후보별 검토 기록은 로컬 `_workspace/docs-2026-10-26-001/`에 보관했다. 이 작업에서 바꾼 파일만 커밋하며, 기존 미추적 `scripts/`는 포함하지 않는다.
