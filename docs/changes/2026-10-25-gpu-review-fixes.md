# GPU 11편 정독 리뷰 보정 기록

2026-10-25에 GPU 11편과 시리즈 색인을 처음부터 정독 리뷰했다. architect 4명이 편을 나눠 읽었고, 숫자와 모순으로 지적된 항목은 메인이 원문으로 다시 확인했다. 지적은 시리즈 전체 10항목, 편별 8~10건이었다.

## 01~04편 전면 재작성

01~04편은 Astra(`gpt-6-astra`, xhigh, `codex exec --sandbox read-only`)가 제목과 절 구성까지 다시 썼다. 2026-10-21의 두 번째 Astra high 패스에서 01~04만 번호 없는 합쇼체 헤딩으로 바뀌어 05~11과 형식이 갈렸기 때문이다. 리뷰에서 지목된 모순도 재작성 지시에 넣었다. 02의 pod scope 권고, 03의 hostManaged와 IMEX 서비스 mask 조건, 04의 clique 라벨 주체가 그 예다.

검증은 `_workspace/structure-2026-10-25-gpu-0104/verify_candidate.py`로 했다. frontmatter, H1, `##` 번호, 앵커, shortcode, 코드 펜스, URL, 참고 자료를 원본과 multiset으로 대조했고 FATAL은 0건이었다. 의미 보존은 architect가 원본과 후보를 따로 대조했다.

## 05~11편 최소 교체

05~11편은 틀린 문장만 바꿨다. 사실 확인은 각 편 참고 자료의 URL로 했다.

- 07의 DraNet 수치는 정렬 대 비정렬 비교가 아니라 둘 다 비정렬인 예시였다. 문서 표기를 그대로 따르고 단위가 적혀 있지 않다는 점을 밝혔다.
- 07의 EFA hugepages 5128페이지는 노드에 미리 할당하는 값이고, 5120Mi는 파드 요청 예시다. 둘을 구분했다.
- 09의 p5 EFA "8개"는 FSx 스크립트의 기본 구성이고, 07의 "32개"는 인스턴스 최대치다. 각각 그렇게 적었다.
- 09의 GCP NIC는 200 Gbps Titanium 2개로, 합이 400 Gbps다.
- 08과 09의 SPDK TCP 코어 수는 표의 범위인 16~32로 맞췄다.
- 10에는 xAI 보도자료의 60%에서 95%로 오른 비교를 보충했다. NVSWITCH_FAILURE_MODE는 NVSwitch가 6개인 A100 세대에만 해당한다고 명시했다.
- 11의 DCQCN 체크리스트를 10편의 경고와 맞추고 참조 절 번호를 고쳤다.
- 06·07·11과 색인에는 Kubernetes 1.37.1이 Network Operator 26.7의 지원표(1.32~1.36) 밖이라는 점을 적었다.

## 형식 정리

05와 06 제목에서 콜론과 "1부/2부"를 뺐다. 시리즈 전체에서 부 표기를 없앤 것이다. 불릿, 표 셀, "확인하지 못한 것" 목록의 합쇼체는 평서체로 바꿨다. 용어는 device plugin, DraNet, InfiniBand, NIC의 조사(이/을/과), 온프레미스, DMA-BUF, NVMe-oF RDMA, 약어 풀이 표기로 통일했다.
